// 01. Context & Problem Statement

The Challenge & The Solution

Bridging the gap between manual classroom prep and automated digital generation

✕ The Problem

  • Manual Formatting Overhead: Creating word scrambles and arithmetic drills in standard word processors is tedious, error-prone, and time-consuming.
  • Isolated Physical Content: Extracting word lists from physical textbooks or curriculum papers requires manual re-typing and transcription.
  • Uncontrolled Difficulty: Random math drills often produce negative answers for beginners or messy division remainders that disrupt young learners.
  • Printing & Paper Waste: Many online generators create bloated single-column layouts that waste school paper and costly color ink.

✓ The Solution: Scramble Quest

  • Instant Dynamic Scrambling: Curated age presets (Ages 4–12+) and custom scrambled puzzle generation with a single tap.
  • On-Device OCR & Multi-File Ingestion: Snap a photo of a textbook or upload PDF/Word/Excel sheets to instantly extract clean word banks.
  • Engineered Math Generators: Strategy-pattern engine ensuring non-negative subtraction and clean, whole-number division across Grades 1–7.
  • Smart 2-Column PDF Engine: High-density layout with automated teacher answer keys and an "Ink-Saver" black & white mode.

// 03. Software Architecture

Design Patterns & Code Structure

A maintainable, decoupled codebase adhering to solid object-oriented principles

lib/
├── main.dart               # Root & Scramble View
├── theme_manager.dart      # Reactive Theme Controller
├── age_word_presets.dart   # Curated Word Banks
├── pdf_style_dialog.dart   # PDF Style Selection
├── sum_generator_page.dart # Math Generator UI
└── sum_generator/          # Strategy Pattern
    ├── sum_generator_base.dart
    ├── sum_generator.dart  # Factory Method
    ├── grade_1.dart ... grade_7.dart

Strategy & Factory Patterns

The math engine delegates problem creation to isolated, grade-specific generators (Grade1Generator through Grade7Generator) adhering to the SumGenerator abstract contract. This decouples educational difficulty rules from UI components.

Lightweight Reactive State

Employed Flutter's native ValueNotifier<ThemeMode> and ValueListenableBuilder for instant global theme updates, paired with SharedPreferences for zero-overhead local persistence.

Data Sanitization Pipeline

Raw inputs from varying file formats (OCR bounding blocks, spreadsheet cells, AST document nodes) are routed through a centralized text sanitizer that strips non-alphabetic noise, validates token length, and eliminates empty rows.

// 05. Key Takeaways

Impact & Engineering Learnings

Realized outcomes and architectural reflections

Scramble Quest demonstrates how modern mobile and web technologies can bridge the gap between digital convenience and tactile, real-world educational activities. By implementing solid software engineering principles—such as Strategy and Factory patterns for algorithmic math generation and client-side OCR processing—the project delivers an effortless utility for teachers and parents.

Key technical takeaways include optimizing multi-format AST parsing across irregular spreadsheets and documents, architecting efficient 2-column vector PDF canvas layouts, and maintaining seamless cross-platform performance across both native mobile runtimes and web browsers.
